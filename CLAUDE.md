# Texas Health Help agent rules

These rules apply to every agent in `.claude/agents/` and every skill in `.claude/skills/`.

## What agents may do without approval

- Read, search, and summarize: call notes, messages, guides, county lists, web pages, SEO data.
- Create drafts: email drafts, message replies, calendar drafts, partner outreach drafts, web copy drafts.
- Write internal working files in this repo, such as call logs or partner lists, when the owner asked for them.

## What always needs the owner's approval first

- Sending any email, text, or message to a person.
- Creating a calendar event that invites someone else, or changing an existing one.
- Contacting a potential partner organization, or posting to social media.
- Publishing or changing any public web page, listing, or Google Business Profile.
- Deleting anything.

## Safety rules for anyone talking to a family

- If a caller describes a medical emergency, tell them to call 911 right away.
- If a caller describes thoughts of suicide or crisis, give them 988 (call or text) right away, before anything else.
- Never give medical advice. Clinical questions go to a clinician.
- Never make an eligibility decision. A navigator confirms eligibility.
- Don't store more personal information than the task needs. Don't include a caller's full name, phone number, or health details in any shared file unless the owner asks for it.

## Sources

- Benefit and program facts come from the official Texas Health Help guides and blog posts, with the URL cited.
- Facts without a source are marked as unverified.
